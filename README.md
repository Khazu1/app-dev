# My Favorite Series: Darling in the Franxx

*Darling in the Franxx* is a sci-fi romance and mecha anime set in a post-apocalyptic future where humanity fights giant creatures called Klaxosaurs.

## Main Characters
* Hiro (Code:016)
* Zero Two (Code:002)
* Ichigo (Code:015)
* Goro (Code:056)

## Quick Facts
1. **Genre:** Mecha, Sci-Fi, Romance, Drama
2. **Director:** Atsushi Nishigori
3. **Studios:** Trigger and CloverWorks

> "A bird with only one wing cannot fly unless it embraces its partner."
